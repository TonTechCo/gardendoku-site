# gardendoku-site

Static support site for **Gardendoku**, a TonTech mobile puzzle game (`com.tontech.gardendoku`): home page, privacy policy, terms and support FAQ. Plain HTML and one CSS file, no build step, no JavaScript.

Published with GitHub Pages at https://tontechco.github.io/gardendoku-site/

## Run locally

```
python3 -m http.server
```

then open http://localhost:8000/

## Notes

- `assets/icon.png` is a placeholder; replace it with the real icon, keeping the file name.
- `config/remote.json` is generated by the game repo (see `config/README.md`).
- AppAdmin does not write here. Ad settings live in AppAdmin's direct feed.
- Store badge links are `#` until the store records exist.
